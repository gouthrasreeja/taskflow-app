# TaskFlow

A full-stack task management web application that helps individuals and small teams organize, track, and complete their daily tasks.

## Overview
TaskFlow centralizes task creation, status tracking, and progress visibility into a single, simple interface — built as part of the YuvaIntern Junior Full Stack Developer Internship.

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js + Express
- **Database:** MongoDB (Mongoose)
- **Auth:** JWT (JSON Web Tokens)

## Planned Features
- User registration and secure login
- Create, view, edit, and delete tasks (CRUD)
- Task status tracking: Pending / In Progress / Done
- Search and filter tasks
- Due dates with overdue indicators
- Per-user data isolation

## Project Status
- ✅ Week 1: Project planning, system architecture, wireframes, and database schema design completed
- 🔄 Week 2 onward: Implementation in progress

## Architecture
Three-tier architecture — React client → Express REST API → MongoDB database (via Mongoose).
